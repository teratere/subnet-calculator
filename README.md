# 🌐 IPv4 サブネット計算機 (IPv4 Subnet Calculator)

IPアドレスとサブネットマスク（CIDR）を入力するだけで、ネットワークアドレス、利用可能ホスト範囲、そしてネットワーク部・ホスト部の**2進数（32ビット）構造を直感的に可視化**するシングルファイルWebツールです。

---

## 🌟 主な機能 (Features)

### 1. リアルタイム連動入力
- **CIDRプルダウン ⇄ プレフィックススライダー同期:** `/1` 〜 `/32` の任意のプレフィックスを直感的に選択・スライダー操作可能
- **プリセットボタン:** Class C (`/24`)、Class B (`/20`)、Class A (`/16`) の代表的な構成を1クリックで呼び出し

### 2. 包括的なアドレス情報算出
- **基本ネットワーク情報:** ネットワークアドレス、ブロードキャストアドレス、サブネットマスク、ワイルドカードマスク、IPクラス
- **ホスト割り当て情報:** 利用可能IPの最初・最後、利用可能ホスト数、総IPアドレス数、アドレス種別（プライベート / パブリック / ループバック 等）
- **エッジケース対応:** RFC 3021（`/31` Point-to-Pointリンク）や単一ホスト（`/32`）の特殊計算に対応

### 3. 2進数ビット内訳の可視化 (Binary Visualizer)
- 32ビットをオクテット（8ビット×4組）単位でドット区切り表示
- **ネットワーク部（青系）** と **ホスト部（緑系）** をカラーバッジで明快に色分け表示

### 4. 完全ローカル・プライバシー保証
- 計算ロジックはブラウザのJavaScript（ビット演算）のみで完結
- ネットワーク通信を一切行わないため、社内LANやプライベートIPの計算も安全に実行可能
